# Cupid Programmer Union

Linux tools, reusable libraries, and console emulators, maintained by [Frank](https://github.com/frankischilling). C is the main language here, with projects in C++ and Rust too.

## Linux and terminal tools

- [cupidfm](https://github.com/cupidthecat/cupidfm): an ncurses file manager with file previews, Git status, and scriptable plugins.
- [cupidterminal](https://github.com/cupidthecat/cupidterminal): an X11 terminal emulator with scrollback, Unicode support, and font fallback.
- [cupidwm](https://github.com/cupidthecat/cupidwm): a compact X11 window manager written in C.
- [cherubsh](https://github.com/cupidthecat/cherubsh): a shell written in Rust, targeting Bash compatibility.
- [cupidfetch](https://github.com/cupidthecat/cupidfetch): a system information tool for Linux.
- [cuPID](https://github.com/cupidthecat/cuPID): an ncurses process monitor with CPU and memory views.

Smaller utilities include the [cupid-ed text editor](https://github.com/cupidthecat/cupid-ed), [cupid-clip clipboard tool](https://github.com/cupidthecat/cupid-clip), and [cupid-lc line counter](https://github.com/cupidthecat/cupid-lc).

## Libraries and scripting

Several of these projects work together. cupidfm uses the libraries below for previews, configuration, Git status, and plugins.

- [cupidimage](https://github.com/cupidthecat/cupidimage): image decoding and terminal graphics through ANSI truecolor, Kitty, and Sixel. PDF rendering is under active development.
- [cupidarchive](https://github.com/cupidthecat/cupidarchive): archive inspection and extraction in C.
- [cupidscript](https://github.com/cupidthecat/cupidscript): an embeddable scripting language implemented in C.
- [cupidconf](https://github.com/cupidthecat/cupidconf): a C configuration library.
- [cupidgit](https://github.com/cupidthecat/cupidgit): a read-only Git library for status detection.

## Console emulation

- [cupid-nes](https://github.com/cupidthecat/cupid-nes): NES and Famicom.
- [cupidgb](https://github.com/cupidthecat/cupidgb): Game Boy and Game Boy Color.
- [cupidgba](https://github.com/cupidthecat/cupidgba): Game Boy Advance.
- [cupid-snes](https://github.com/cupidthecat/cupid-snes): Super Nintendo.
- [cupid-n64](https://github.com/cupidthecat/cupid-n64): Nintendo 64, 64DD, and Aleck64.
- [cupid-ps1](https://github.com/cupidthecat/cupid-ps1): PlayStation.
- [cupid-8](https://github.com/cupidthecat/cupid-8): CHIP-8.

See each repository for build instructions, current support, and known issues.
